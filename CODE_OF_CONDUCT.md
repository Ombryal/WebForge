# WebForge Code of Conduct

## Our Pledge
WebForge is a project built to simplify website development. To achieve this, we need a collaborative, focused, and respectful community. We pledge to make participation in our project a harassment-free experience for everyone, regardless of experience level, gender identity, disability, ethnicity, or background.

## The Short Version
Be respectful, be constructive, and assume good faith. Disagreements about syntax, compiler architecture, and language design are normal and welcome. Personal attacks, harassment, and discrimination are not.

## Expected Behavior
As an early-stage language project, we rely on focused collaboration. We expect participants to:

- **Critique ideas, code, and syntax—not people.** Focus on the technical merits of a proposal or implementation.
- **Accept that reasonable people can disagree on language design.** Preferences for paradigms, syntax styles, and web standards vary. Disagreements should be resolved with technical arguments, not toxicity.
- **Be patient and helpful.** WebForge is a small, early-stage project maintained in spare time. Issue triage, code reviews, and compiler feedback may take some time. Be kind to beginners and those asking questions.
- **Stay on topic.** Keep discussions focused on WebForge's goals. Avoid excessive "bikeshedding" (arguing over trivial details) that stalls progress.

## Unacceptable Behavior
Examples of unacceptable behavior by participants include:

- **Personal attacks:** Harassment, insults, derogatory comments, or targeted attacks in Issues, PRs, or any other project space.
- **Discriminatory language:** Jokes or remarks based on protected characteristics.
- **Trolling and derailment:** Deliberate intimidation, sustained disruption of discussions, or excessive off-topic arguments.
- **Doxxing:** Publishing others' private information without explicit consent.
- **Spam:** Irrelevant links, excessive self-promotion, or spamming the repository.
- **Anything else** that would make a reasonable person feel unwelcome, unsafe, or unwilling to participate.

## Scope
This applies to all WebForge project spaces, including GitHub Issues, Pull Requests, Discussions, commit messages, and anywhere someone is representing the project externally.

## Enforcement
Given the project's current size, moderation is at the maintainer's discretion. Enforcement follows a fair escalation path:

1. **Correction:** A request to rephrase or clarify an unacceptable comment.
2. **Editing/Removal:** Modifying or deleting content that violates the CoC.
3. **Exclusion:** Temporarily or permanently blocking a user from further participation in the project's GitHub repository.

### Reporting
If you experience or witness behavior that violates this document, please report it:
- Tag **@Ombryal** in a relevant Issue or Discussion.
- Check the project `README.md` for direct contact information (email/DM) if the issue is private.

All reports will be kept confidential where possible and handled promptly based on the severity of the incident.
